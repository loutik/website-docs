# Réferentiel gestion des Tags

## A. Règles

  * **Format :** Uniquement du kebab-case (minuscules, sans accents, séparés par des tirets).
  * **Quantité :** 3 tags par article au maximum.
  * **Formule idéale :** 1 Domaine + 1 Technologie + 1 Concept.

## B. Les tags disponibles

* **Catégorie A : Les domaines (Le cadre de l'article)**
    * homelab (Infrastructures locales, expérimentations matérielles)
    * bts-sio (Préparations aux CCF, projets académiques, stages)
    * loutik (Projets liés à ton activité freelance, audits, hébergement)

* **Catégorie B : Les technologies (L'outil principal utilisé)**
    * k3s / kubernetes
    * proxmox
    * ansible
    * docker / podman
    * opnsense
    * linux (Ubuntu, Fedora, etc.)
    * astro / starlight

* **Catégorie C : Les concepts (La notion technique abordée)**
    * iac (Infrastructure as Code)
    * gitops
    * automatisation
    * reseau (VLAN, DNS, LoadBalancing)
    * securite (WAF, audits, durcissement)
    * sauvegarde (Rétention, plans de reprise)
